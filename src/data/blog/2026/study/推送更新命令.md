`cd Satechan.github.io`

`git add .` 將所有修改過的新增或刪除檔案從工作區加入到暫存區，準備進行打包。

`git commit -m "feat: "` 將暫存區的檔案正式打包並加上提交信息，在本地產生一個版本快照。

`git push` 將本地已提交的最新版本推送到遠端 GitHub 倉庫，自動觸發雲端構建並更新線上博客。

`git status` 查看當前狀態

```bash
git add .
git commit -m "feat: 更新"
git push
git status
```
